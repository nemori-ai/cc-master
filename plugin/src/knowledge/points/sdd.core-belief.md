## 核心信念（道）

**Spec（规约）先于实现。** 这不是工具偏好，是认识论立场：

> 你只能对照某个外部标准来判断实现是否正确。  
> 如果那个标准是实现本身——正确性是无意义的。

Spec 就是那个**先于实现达成的外部标准**：消费者与实现者之间在任何一行代码落下之前共同签署的合约。实现派生自 spec，测试对着 spec 验收，文档描述 spec——三者的**单一真相源（SSOT）是 spec，不是其中任何一个**。

这是五根里**根 2（契约即 SSOT）的本命落点**。SDD 整条立在这根上：当你的实现、测试、文档三者发生分歧，正确答案永远是「回到 spec，spec 说什么就是什么」。
