# 不收敛是诊断信号，不只是熔断条件

<!-- ccm:k:start point:preference.non-convergence-as-signal -->

评审轮次上限那个保险丝，是用来防止无限循环的。它同时还是一个**你多半没在用的信号源**：一件事反复评不过，除了"该收工了"，还有另一种解释——**上游有系统性盲区，你正在下游反复修它的症状。**

这个信号比执行者自省硬得多。自省要求钻牛角尖的人承认自己钻了牛角尖；**轮次计数不需要任何人承认，它在验收侧自动累积。**

看到轮次逼近上限时，不要只在「再修一轮」和「收工」之间选。第三个动作是**回到上游**：需求本身有歧义吗？验收判据当初就写含糊了吗？切分把两件事捆在了一起吗？——这些在下游怎么修都修不掉。

**但「我觉得上游有盲区」是放弃一个只差两轮就收敛的方案的完美借口**，所以它必须配硬判据。回溯之前对照：

1. **各轮的问题落在同一维度吗？** 每轮都是不同方面的零散问题 → 就是还没做完，继续修。反复撞同一类问题 → 上游信号。
2. **每轮在修新出现的问题，还是同一个问题的又一个面？** 后者说明你在打地鼠，洞在别处。
3. **修完这一条，你说得出下一条会是什么吗？** 说得出且屡次说中 → 你已经知道根因在上游，只是在逐个处理它的表现。

**两条以上命中才回溯。** 一条都不命中而想回溯的，那不是诊断，是想换个题目做。

## 失效类型

`motivation_conflict` —— 「反复不收敛可能说明上游有问题」这个推理不难，强模型推得出来。它不做，是因为**熔断已经提供了一个体面的出口**：到上限就收工，形式上合规、有据可依、不必承认任何事。走那个出口比回溯上游省事得多。

而反向的自毁同样是动机问题：回溯是个体面的放弃姿势。所以这条的两侧都落在这一档，硬判据就是为了让两侧都不便宜。

## 边界

不管**同层内的重启**（换思路、换起点、重切验收）——那是执行循环里的动作，换的是方法。这条讲的是**跨阶段回溯**，回到切分、验收判据、甚至需求本身。

也不管熔断本身该设几轮。

## 失败形态

这条知识在图上的三段是齐的——可观测信号有、上游盲区的概念有、重启动作有——**缺的是把它们连起来的那两条边。** 于是三段各自都在，谁也不会在看到轮次计数时想到上游，因为没有任何东西把它们放在同一段推理里。**知识齐备而链断开，表现出来和不知道完全一样。**

> 连接「不收敛」与「上游阶段」的那条跨界导航边目前表达不出来——图上的跨技能边尚未开放。这条知识先立住，边等结构放开后补。**在那之前，这段推理只能靠正文自己说全，不能指望导航把读者带过去。**
